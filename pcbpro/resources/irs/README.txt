Built-in guitar cabinet impulse responses
=========================================

1x12_open.wav, 2x12_closed.wav, 4x12_slant.wav, 4x12_straight.wav

Public domain. They come from the "650 Assorted Cabinet Impulses" pack by zoyd on musical-artifacts.com
(https://musical-artifacts.com/artifacts/252), which was released into the public domain. These copies were taken
from the 0xFX project (https://github.com/averagenative/0xFX, resources/ir/bundled), which uses the same four.

Format: 32-bit float WAV, stereo, 44.1 kHz. PCBPro mixes them to mono and resamples them to the audio rate.

Original names: cambridge 1x12 (1x12 open), allston 2x12 (2x12 closed), worcester stack (4x12 slant),
northbridge 4x12 (4x12 straight).
